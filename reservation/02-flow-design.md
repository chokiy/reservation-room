# 02. 사용 흐름·디자인 — 회의실 예약 앱

## 핵심 시나리오

**S1. 사전 예약 (데스크톱, 주 1~2회)**
1. 기획팀 민수가 월요일 아침에 로그인한다. 목요일 오후 2시에 팀 회의를 잡아야 한다.
2. 상단 날짜 바에서 목요일을 고르면 회의실 10개 × 시간 그리드가 보인다.
3. 14:00~15:00 구간에서 빈 방을 찾아, 회의실3의 14:00 칸에서 15:00까지 드래그해 선택한다.
4. 예약 창에서 제목 "스프린트 리뷰"를 입력하고 참석자 4명(다른 팀 1명 포함)을 지정한 뒤 **[예약] 버튼**을 눌러야 저장된다.
5. 같은 칸에 다른 팀이 먼저 예약했다면 "방금 예약되었습니다. 다른 시간을 선택하세요"라고 안내한다.

**S2. 즉흥 예약 + 수정 (모바일, 하루 여러 번)**
1. 개발팀 지은이 폰으로 접속하면 오늘 화면 맨 위에 "지금 비어 있는 방" 띠가 보인다.
2. 회의실7의 [지금 예약]을 누르면 예약 창이 열리고 가장 가까운 30분이 미리 채워진다(시간 변경 가능).
3. **제목과 참석자를 지정하고 [예약] 버튼**을 눌러야 반영된다. 제목이나 참석자가 비어 있으면 버튼이 비활성화된다.
4. 나중에 참석자로 지정된 동료가 예약을 열어 제목·참석자를 고치고 **[수정] 버튼**을 눌러야 반영된다. 누르지 않고 닫으면 원래 내용이 유지된다.

## 화면 구조
- `/login`, `/signup`(팀 선택)
- `/` **현황 그리드** (메인)
- **예약 창**(생성/수정 겸용 모달·시트)
- `/my`: 내 예약, 참석 예약 목록
- 흐름: `로그인 → 현황 그리드 → 예약 창 → 현황 그리드`

## 확정 디자인: 하이브리드 (가로 시간축 타임테이블)

**철학**: 방 10개를 세로로 쌓고 시간을 가로로 흘려서, 한 행만 훑어도 그 방의 하루가 읽힌다. 상단에 "지금 비어 있는 방" 띠를 둔다.
**무드**: 흰 배경 + 남색 포인트, 정보 밀도가 높은 차분한 톤. 예약된 칸은 팀별 색 블록에 팀명과 제목을 표시한다. 비어 있는 방은 초록, 사용 중인 방은 주황 배지를 쓴다.

```
┌─────────────────────────────────────────────────────────────────────┐
│ 회의실 예약                                  민수(기획팀) ▾   내 예약 │
├─────────────────────────────────────────────────────────────────────┤
│ 🟢 지금 비어있는 방: [회의실1] [회의실3] [회의실7] [회의실9]  ← 원탭 예약│
├─────────────────────────────────────────────────────────────────────┤
│ ◀  2026-10-22 (목)  ▶    [오늘]   [📅 날짜 선택]                      │
├────────┬────────────────────────────────────────────────────────────┤
│        │ 08  09  10  11  12  13  14  15  16  17                      │
│        │ :0:3:0:3:0:3:0:3:0:3:0:3:0:3:0:3:0:3                       │
├────────┼────────────────────────────────────────────────────────────┤
│회의실1 🟢│ □□□□□□▓▓▓▓▓□□□□□□□□□□□□□□□□                                │
│회의실2 🟠│ □□▓▓▓▓□□□□□□□□▓▓▓▓□□□□□□□                                │
│회의실3 🟢│ □□□□□□□□□□□□□□░░░░□□□□□□□□  ← 14:00~15:00 드래그 선택       │
│회의실4  │ ▓▓▓▓▓▓▓▓□□□□□□□□□□□□□□□□□                                  │
│  ...   │                                                             │
│회의실10 │ □□□□□□□□□□□□□□□□□□□□□□□□□□                                  │
└────────┴────────────────────────────────────────────────────────────┘
 ▓ 예약됨(칸을 누르면 상세·수정·취소)   □ 빈칸(누르거나 드래그해서 예약)
```

- **가로 = 시간** (08:00~17:00, 30분 칸 18개), **세로 = 회의실** (10행), **날짜는 상단 날짜 바**로 이동한다. (가정)
- 칸 선택: 클릭 또는 드래그로 연속 슬롯을 선택하면 예약 창이 열린다.
- 예약된 칸을 누르면 상세가 열린다. 예약자·참석자는 [수정], 예약 팀원은 [취소]를 쓸 수 있다.
- 현재 시각 세로선을 표시하고, 지난 칸은 회색으로 막는다.
- **모바일**: 방 이름 열은 고정(sticky)하고 시간 영역만 가로 스크롤한다. 오늘을 열면 현재 시각 근처가 보이도록 스크롤한다. "지금 비어 있는 방" 띠는 맨 위에 유지한다.

## 예약 창 (생성/수정 겸용)
- 입력: 방·날짜·시작~종료 시각, **제목(필수), 참석자(필수, 1명 이상, 사내 사용자 검색 선택)**
- 생성 모드: [예약] 버튼으로 저장. 수정 모드: [수정] 버튼으로 저장. 닫으면 변경을 버린다.
- 저장 시 겹침을 검사하고, 실패하면 이유를 보여준다.

## (가정) 목록
- 날짜는 세로가 아니라 상단 날짜 바로 이동하고, 세로축은 회의실이다.
- 하이브리드의 "지금 비어 있는 방" 띠를 포함한다.
- 지난 시간은 선택·예약 불가.
- 참석자는 1명 이상 필수.
